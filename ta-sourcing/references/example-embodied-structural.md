## Lessons

- 官网飞书 ATS 的公开 API 是 `POST /api/v1/search/job/posts`, 不需要登录. 返回 JSON 含 `description` 和 `requirement`, 但无薪资.
- 官网智联 zhiye 门户 HTML 不吐岗名, 不要浪费时间解析.
- Moka 列表接口加密, 静态页 0 岗, 直接标 "官网列表加密".
- 年包只在 月薪 × 年薪月数 齐全时计算; 官网一律 "官网未披露".
- 自变量把整机结构拆成 负责人 / 执行 / 模块 PL / 电机结构 / 微型齿轮 五层; 众擎把关节、本体、灵巧手拆开; 逐际专家岗是带队+架构.
